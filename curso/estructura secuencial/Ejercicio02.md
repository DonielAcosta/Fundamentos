# Ejercicio 2 — Expresiones matemáticas en C++

**Fuente:** EjerciciosSecuencialidad01.pdf

| Expresión matemática | Expresión en C++ |
|----------------------|------------------|
| b | `b` |
| c + a | `c + a` |
| xy | `x * y` |
| 1 − 4Zx | `1 - 4 * Z * x` |
| x + y | `x + y` |
| x − y | `x - y` |
| (a + b) / c | `(a + b) / c` |
| 1/2 + 2/3 | `1.0/2 + 2.0/3` o `1/2.0 + 2/3.0` |
| 2² | `2 * 2` o `pow(2, 2)` |
| ((a + b) / c)² | `((a + b) / c) * ((a + b) / c)` o `pow((a + b) / c, 2)` |
| hola mundo | `"hola mundo"` |

> **Nota:** En C++, `1/2 + 2/3` con enteros da **0** (división entera). Use literales reales para obtener 0.833...
